# Neuronaut

**A voyage through the complete wiring diagram of a fruit fly brain.** The site uses real data from the [FlyWire](https://flywire.ai) connectome: 139,255 neurons and 54.5 million synapses, shown in 3D in the browser.

Neuronaut is a static website built with three.js and d3, with no build step. Everything on screen is derived from public data:

| Station | What you see | Data |
| --- | --- | --- |
| 01 Slice | Real electron-microscope sections sweeping through the brain in 3D. A microscope view zooms from the whole optic lobe (512 nm/px) down to single synaptic vesicles (8 nm/px), with the AI segmentation overlaid. | FAFB / FlyWire EM, `flywire_v141_m783` segmentation |
| 02 Assembly | Every proofread neuron appears front to back, then real neuron skeletons grow out of their cell bodies. | FlyWire v783 annotations + skeletons |
| 03 Census | An interactive census by cell class, neurotransmitter, hemisphere or developmental lineage. | Schlegel et al. 2024 annotations |
| 04 Territories | The 78 neuropils as glowing shells, plus a matrix of where each region's neurons send their output. | FlyWire neuropil meshes, per-neuron neuropil synapse counts |
| 05 Wiring | 36,000 strong connections drawn as arcs through the neuropil where their synapses sit, coloured by transmitter. | `proofread_connections_783` |
| 06 Characters | Famous cells as real morphologies: the head-direction compass, Giant Fiber, moonwalker, memory centre, motion detectors, clock and more. | FlyWire skeletons |
| 07 Pulse | Whole-brain spiking simulations (sugar, bitter, smell, light, sound, grooming, looming) replayed on the 3D brain, with spike raster and signal pathway. | Leaky integrate-and-fire model after Shiu et al. 2024, re-run on v783 |
| 08 Scale | How this map compares with every other connectome. | Literature |
| 09 Explore | Search any of 8,800+ cell types or a root ID, click any neuron to see its strongest partners, filter and recolour. | All of the above |

## Run it locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

Any static file server works. The page loads three.js and d3 from jsDelivr and fonts from Google Fonts. Deploying to GitHub Pages works as is.

For hosts that only serve web media types, `python tools/pack_png.py OUT_DIR` writes a copy of the site whose `.bin` files are wrapped losslessly as PNGs (about 40% smaller). The page unwraps them in the browser.

## Data pipeline

The browser assets in `data/` are generated by the scripts in `pipeline/`, from these sources:

- [FlyWire connectivity, Zenodo 10676866](https://zenodo.org/records/10676866): `proofread_connections_783.feather`, `per_neuron_neuropil_count_*_783.feather`, `proofread_root_ids_783.npy`
- [flyconnectome/flywire_annotations](https://github.com/flyconnectome/flywire_annotations): neuron annotations
- [philshiu/Drosophila_brain_model](https://github.com/philshiu/Drosophila_brain_model): LIF model and v783 connectivity
- Public Google Cloud buckets: `flywire_em` (EM), `flywire_v141_m783` (segmentation + skeletons), `flywire_neuropil_meshes`

```bash
export FLY_RAW=/path/to/raw/downloads      # default /home/user/data
cd pipeline
python build_neurons.py        # neurons.bin / neurons.json / root_ids.bin (defines the neuron index)
python build_neuropils.py      # neuropils.bin / neuropils.json
python build_connectivity.py   # connectome.json, arcs.bin, partners/p###.bin
python build_skeletons.py      # featured.bin, forest.bin
python build_em.py             # data/em/*
python build_sim.py            # data/sim/*  (numba LIF, validated against Brian2)
```

Binary files use a simple container written by `pipeline/common.py:write_columns`: a uint32 header length, a JSON directory of named arrays, then 8-byte aligned little-endian arrays the browser views as typed arrays. All 3D positions share one frame, in micrometres centred on the FAFB volume.

## Honest caveats

- Transmitters are predicted from EM images (Eckstein et al. 2024), not measured.
- The simulation is a simple model. It ignores neuromodulation, gap junctions and learning, and signs synapses by predicted transmitter. Photoreceptors therefore excite rather than inhibit, and strong odour input can ignite runaway activity; the smell run is driven at 100 Hz for that reason. Each run notes its caveats in the interface.
- 139,248 of the 139,255 proofread neurons carry annotations and positions; the site shows those.
